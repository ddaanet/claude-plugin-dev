## Remaining

- Consumer flow, after the self-release slice: the same release-from-dev design in `toolkit/`, a second implementation since the two share no code. It covers `common_preflight` in `toolkit/release-preflight.sh`, its "must be on" refusal, and `push_branch` in `toolkit/release-publish.sh`. Until it lands, `ddaa:preflight` accepts dev while a consumer's recipe still refuses it.
- Same design, requirements for the consumer flow: fetch first and refuse unless `main` and `origin/main` are both ancestors of `HEAD`; allow only `main` and `dev` as the release branch, so a half-finished plan branch stays refused; `--resume` pushes the tag's commit, not `HEAD`, and its already-pushed probe compares against that, so later dev commits are not published; `--resume` refuses a tag whose commit is not an ancestor of `HEAD`, as the self-release does. Existing refusal tests and `docs/references/release-flow.md` change with it. To be weighed there: a half-landed release cannot finish once origin's `main` gains a commit the tag's commit lacks, because preflight refuses, and after a merge into `dev` the push of the tag's commit is non-fast-forward. That is declined for the self-release, where only releases move `main`, but a consumer's `main` may have other writers.
- The `ddaa` preflight change reaches sessions only through a release of `/Users/david/code/skills`, which has not been requested: raise it once the edit lands.
- The root `README.md` list "What a consumer plugin gets" omits `just check-size`; it predates 0.15.0, so that release's preflight left it.
- Amending a release commit after its tags are cut, which `docs/references/recovery.md` already advises against, has two rough edges left in `scripts/self-release.sh`. `ensure_dist_tag` keeps an existing local dist tag without comparing it to the tag, so a hand retag publishes `dist-vX.Y.Z` from the old `toolkit/` tree; comparing `$dist_tag^{tree}` with `$tag:toolkit` would close it, but adds a refusal, so propose it first. From `dev` after a failed push, the run stops at `local main is not an ancestor of HEAD` with no way out named; `main` has to move back by hand first.
