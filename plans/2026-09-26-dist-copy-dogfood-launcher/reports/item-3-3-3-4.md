## Reflow of both files

Before any edit, `.venv/bin/rumdl check README.md toolkit/README.md` failed on
the committed files: 55 MD013 findings, 28 in `README.md` and 27 in
`toolkit/README.md`. The READMEs were hand-wrapped at about 72 columns, and
`.rumdl.toml` uses `reflow-mode = "normalize"`, which flags any paragraph not
filled to 80 columns. Passing the required check therefore meant reflowing each
whole file, so I ran `rumdl fmt` on each README after editing it. Each commit
carries that reflow as well as the content change.

Before running it, I checked on copies that the reflow changes line breaks only.
`git diff --no-index --word-diff=porcelain` showed no word added or removed, and
fenced blocks are exempt (`code-blocks = false`).

After the edits, the only removed words in either diff are these four, each
re-added with the new text:

- `` `check-version` ``
- `` `update-plugin-dev`. ``
- `` `update.sh`. ``
- `` `gh`. ``

The two full warning strings would not fit in 80 columns as inline code, so they
sit in a `text` fenced block, which the formatter does not wrap.
